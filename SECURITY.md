# Security Policy

## Supported Versions
The latest commit on the main branch receives security updates.

## Reporting a Vulnerability
While the framework has a very small attack surface and does not perform any networking or process any external data, security issues are still appreciated.

Please open a private GitHub security advisory if available or contact the maintainer directly via marcoaklima@gmail.com rather than opening a public issue.

Examples of security concerns include:
- Memory corruption
- Undefined behaviour causing exploitable crashes
- Integer overflows affecting native code
